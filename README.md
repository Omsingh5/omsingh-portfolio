# Omsingh Rajput — Portfolio

A production-grade personal portfolio built with React.js, featuring interactive 
charts, real-time maps, animated UI, and PWA support.

🔗 Live: [omsingh-rajput.netlify.app](https://omsingh-rajput.netlify.app)

---

## Tech Stack

**Frontend**
- React.js + Vite
- Recharts (Radar Chart)
- Chart.js (Polar Area Chart)
- Leaflet.js (Interactive Map)
- PWA ready

**Design**
- Dark futuristic theme
- Custom animated cursor
- Intersection Observer scroll animations
- 3D tilt cards
- Matrix code rain canvas

---

## Features

- Hero section with animated code rain background
- Skills section with animated bars + dual charts
- Projects showcase with 3D tilt cards
- Backend architecture code viewer (REST, JWT, MongoDB)
- Interactive Leaflet.js map (Pune location)
- Contact form with validation
- Resume download button
- Fully responsive + mobile menu
- PWA installable
